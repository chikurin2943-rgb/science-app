地学先取りプリント（気象・湿度の徹底攻略）

2026.10.06 更新

こんにちは！今回は、中2理科の中でも覚えることが多い「気象分野（地学）」のポイントをぎゅっとまとめた自作プリントを作成しました。

天気とその変化を理解しよう

私たちが毎日見ている「晴れ」「雨」「曇り」「風」などは、すべて大気中で起こっている現象です。天気を理解するためには、単に「雨が降る」「気温が上がる」と覚えるのではなく、一連の流れを理解することが大切です。

1．気象観測と気圧

気象とは？

気象とは、地球を取り巻いている大気の中で起こる、雨・雪・風・雲などのさまざまな現象のことです。

気象を観測するときには、いくつかの「気象要素」に注目します。主な気象要素には、

  • 気温
  • 湿度
  • 気圧
  • 風向
  • 風速

などがあります。これらを組み合わせて観測することで、「なぜ今日は雨なのか」「これから天気がどう変わりそうか」といったことを考えられるようになります。

天気と雲量

天気は、空全体にどれくらい雲が広がっているかなどをもとに表します。雲の量を雲量といい、0～10の11段階で表します。中学校理科では、基本的に次のように覚えます。

雲量と天気
雲量0～1：快晴
雲量2～8：晴れ
雲量9～10：曇り

雨や雪などが降っている場合は、降水の有無も含めて天気を判断します。天気図や気象観測では、決められた天気記号を使って天気を表します。

2．気温・湿度・風の観測

気温

気温は、空気の温度です。気温を正しく測るためには、温度計を地上から約1.5 mの高さに置き、風通しがよく、直射日光が当たらない場所で観測します。

直射日光が当たると、太陽からの熱によって温度計そのものが温められ、本当の空気の温度より高く測定されてしまいます。

湿度

空気には、目には見えない水蒸気が含まれています。空気中にどれくらい水蒸気が含まれているかを表すのが湿度です。

湿度を測るときには、乾湿計を使います。乾湿計には「乾球」と「湿球」という2つの温度計があります。

湿球では、水が蒸発するときに周囲から熱を奪うため、乾球より温度が低くなります。空気が乾燥しているほど水が蒸発しやすいため、乾球と湿球の温度差が大きくなります。逆に、空気が水蒸気を多く含んでいると水が蒸発しにくいため、温度差は小さくなります。この温度差と気温から、湿度表を使って湿度を求めます。

風向と風速

風向とは、風が「吹いてくる方向」です。例えば「北風」といえば、北から南へ向かって吹いてくる風を表します。風向は16方位で表します。

一方、風速は風の速さです。単位にはm/s（メートル毎秒）を使います。また、風の強さを表すときには風力を使うこともあり、風力は0～12の13段階で表します。

3．圧力と気圧

圧力とは？

ものが面を押すとき、その面には力がはたらきます。このとき、面積1 m²あたりにどれだけの力がはたらいているかを表したものが圧力です。圧力の単位はPa（パスカル）です。

圧力（Pa）＝力（N）÷面積（m²）

つまり、同じ力で押すなら、面積が小さいほど圧力は大きくなります。例えば、同じ体重の人が立っていても、靴底の面積が小さい靴を履いているほうが、地面に加える圧力は大きくなります。

気圧とは？

空気にも重さがあります。そのため、私達の上にある大量の空気が、地面や物体を押しています。この大気による圧力を気圧（大気圧）といいます。気圧の単位にはhPa（ヘクトパスカル）を使います。単位の関係は、1 hPa ＝ 100 Pa です。

1気圧とは？

海面付近の平均的な大気圧を基準にしたものを1気圧といい、1気圧 ≒ 1013 hPa（Paに直すと 101300 Pa）となります。

高い山では気圧が低い

山の上に行くと、気圧は低くなります。なぜでしょうか。高い場所ほど、その上に存在する空気の量が少なくなります。つまり、上から押してくる空気の重さが小さくなるため、気圧が低くなるのです。

例えば、山にお菓子の袋を持っていくと、袋がふくらむことがあります。仕組みは以下の通りです。

山に登る ➔ 周囲の気圧が低くなる ➔ 袋の中の空気が外側から押される力が小さくなる ➔ 袋の中の空気が相対的に袋を外側へ押す ➔ 袋がふくらむ

4．空気中の水蒸気

空気中には、目には見えない水蒸気が含まれています。しかし、空気なら無限に水蒸気を含めるわけではありません。温度によって、含むことのできる水蒸気の最大量が決まっています。

飽和水蒸気量

飽和水蒸気量とは、1 m³の空気が、その気温で含むことのできる水蒸気の最大量のことです。空気が飽和水蒸気量まで水蒸気を含んでいる状態を飽和といいます。

重要なのは、気温が高いほど、飽和水蒸気量は大きくなるということです。つまり、暖かい空気ほど多くの水蒸気を含むことができます。

5．湿度の計算

湿度は、「その空気が、最大限含める量に対して、実際にどれくらい水蒸気を含んでいるか」を表しています。したがって、公式は以下のようになります。

湿度（％）＝ 実際の水蒸気量（g/m³）÷ その気温での飽和水蒸気量（g/m³）× 100

例えば、ある気温での飽和水蒸気量が 20 g/m³ で、実際には 10 g/m³ の水蒸気が含まれている場合：
10 ÷ 20 × 100 ＝ 50 なので、湿度は50％です。

湿度が100％になると？

湿度100％とは、空気中の水蒸気量が、その気温での飽和水蒸気量に達している状態です。

ここで注意したいのは、湿度100％＝必ず雨が降っている という意味ではないことです。湿度100％でも、空気中に水滴ができていなければ、必ずしも雨や霧が発生しているわけではありません。

6．露点と凝結

空気を冷やしていくと、ある温度で空気中の水蒸気が水滴になり始めます。このときの温度を露点といいます。つまり、露点＝空気中の水蒸気が冷やされて凝結し始める温度です。

「凝結」とは、水蒸気が冷やされて液体の水になる変化です。例えば、冷たい飲み物を入れたコップの外側に水滴がつくのは、コップによって周囲の空気が冷やされ、その空気中の水蒸気が凝結して水滴になったためです。

7．霧はどうやってできる？

霧は、地表付近の空気中の水蒸気が凝結してできた小さな水滴です。

地表付近の空気が冷やされると、空気の温度が下がります。そして、その温度が露点に達すると、水蒸気が凝結して小さな水滴になります。この水滴が地表付近に浮かんでいる状態が霧です。

【流れ】空気が冷える ➔ 気温が露点に近づく ➔ 露点に達する ➔ 水蒸気が凝結する ➔ 小さな水滴ができる ➔ 霧が発生する

8．雲はどうやってできる？

雲も、基本的には霧と同じく、水蒸気が凝結してできた水滴や氷の粒からできています。では、なぜ空の高いところで雲ができるのでしょうか。ポイントは上昇する空気です。

地表付近の空気が暖められるなどして上昇すると、高いところほど気圧が低くなるため、空気は膨張します。空気が膨張すると、その温度が下がります。

【流れ】空気が上昇する ➔ 周囲の気圧が低くなる ➔ 空気が膨張する ➔ 空気の温度が下がる ➔ 露点に達する ➔ 水蒸気が凝結する ➔ 水滴や氷の粒ができる ➔ 雲ができる

ここが、雲のでき方を理解するうえで最も重要なポイントです。

空気が上昇する理由

空気が上昇する原因は一つではありません。例えば、

  • 地表が太陽に暖められ、空気が暖められる
  • 山に沿って空気が上昇する
  • 前線付近で暖気や寒気が動く
  • 低気圧の周辺で空気が上昇する

などがあります。そのため、「雲は必ず太陽で暖められた空気からできる」と考えないようにしましょう。

9．雨や雪はどうやって降る？

雲の中では、水滴や氷の粒が成長しています。それらが十分に大きくなると、重力によって落下します。地上まで液体の水として落ちてくれば雨、氷の粒や雪として落ちてくれば雪になります。

雨や雪など、空から降ってくる水や氷をまとめて降水といいます。

10．上昇気流と下降気流

上昇気流とは、空気が上向きに動くことです。空気が上昇すると、気圧の低下によって膨張し、温度が下がりやすくなります。そのため、上昇気流がある場所では雲ができやすくなります。

一方、下降気流とは、空気が下向きに動くことです。下降する空気は、周囲の気圧が高くなるにつれて圧縮され、温度が上がりやすくなります。そのため、雲ができにくく、晴れやすくなります。

11．水の循環

地球上の水は、同じ場所にずっと存在しているわけではありません。太陽からのエネルギーによって海や地表の水が蒸発し、水蒸気になります。水蒸気を含んだ空気が上昇して冷やされると、水滴や氷の粒ができて雲になります。そして、雨や雪として地表に戻ります。その水は川や地下水などを通って海へ戻り、再び蒸発します。

このように、蒸発 ➔ 雲の形成 ➔ 降水 ➔ 地表・海 ➔ 蒸発 という循環を繰り返しています。これを水の循環といいます。

12．等圧線と天気図

天気の変化を考えるときには、天気図を使います。天気図には、高気圧・低気圧・前線・等圧線などが示されています。

等圧線とは、気圧の等しい地点を結んだ線です。等圧線を見ることで、どこに高気圧や低気圧があるのか、また気圧の差がどれくらい大きいのかを読み取ることができます。

中学校では、基本的に4 hPaごとに等圧線を引き、20 hPaごとに太い線を使います。

13．高気圧と低気圧

高気圧

周囲より気圧が高いところを高気圧といいます。高気圧では、中心付近から周囲へ空気が流れ出します。そして、上空から空気が下降してきます。

つまり、高気圧 ➔ 空気が下降 ➔ 雲ができにくい ➔ 晴れやすい という関係があります。

日本付近では、北半球にある高気圧の周りでは、地上付近の風は基本的に時計回りに吹き出します。

低気圧

周囲より気圧が低いところを低気圧といいます。低気圧では、周囲から中心へ空気が集まり、中心付近で上昇します。

つまり、低気圧 ➔ 空気が上昇 ➔ 雲ができやすい ➔ 雨や曇りになりやすい という関係があります。

北半球では、低気圧の周りの地上付近の風は基本的に反時計回りに中心へ吹き込みます。

14．気圧と風

風は、基本的に気圧の高いところから低いところへ向かって吹こうとします。つまり、気圧に差があると、その差を小さくするように空気が移動します。

さらに、天気図では、等圧線の間隔が狭い ➔ 短い距離で気圧が大きく変化する ➔ 気圧差が大きい ➔ 風が強くなりやすい と考えます。反対に、等圧線の間隔が広いところでは、風は比較的弱くなりやすいです。

15．前線とは？

空気には、気温や湿度などの性質が異なるものがあります。特に、暖かい空気を暖気、冷たい空気を寒気といいます。

暖気と寒気のように性質の異なる空気が接すると、その境界付近では天気が変化しやすくなります。暖気と寒気が接している境界面を前線面といい、前線面と地表面が交わる線を前線といいます。

前線の通過によって、気温・湿度・気圧・風向・天気などが変化します。

16．温暖前線

温暖前線は、暖気が寒気側へ進んでいく前線です。暖気は寒気より軽いため、寒気の上にゆるやかにはい上がります。そのため、広い範囲で雲ができやすくなります。

温暖前線が近づくと、高層雲などの雲 ➔ 乱層雲など ➔ 広い範囲で比較的弱い雨 というように天気が変化することがあります。温暖前線の雨は、一般に広い範囲で、比較的弱い雨が長時間続きやすいことが特徴です。

温暖前線が通過すると、暖気が入ってくるため、気温が上昇することが多く、風向も変化します。

17．寒冷前線

寒冷前線は、寒気が暖気側へ進んでいく前線です。寒気は暖気より重いため、暖気の下にもぐり込みます。暖気が急激に押し上げられるため、積乱雲などの発達した雲ができることがあります。

そのため、狭い範囲で比較的強い雨・雷や突風などを伴うことがある・短時間で天気が大きく変化する といった特徴があります。

寒冷前線が通過すると、冷たい空気が入ってくるため、気温が下がることが多く、風向も変化します。

18．温暖前線と寒冷前線の違い

温暖前線と寒冷前線は、名前だけで覚えるよりも、「どちらの空気が進むのか」で考えると分かりやすくなります。

  • 温暖前線：暖気が進む ➔ 暖気が寒気の上にはい上がる ➔ 広い範囲に雲が広がる ➔ 比較的弱い雨が長く続きやすい ➔ 通過後は気温が上がりやすい
  • 寒冷前線：寒気が進む ➔ 寒気が暖気の下にもぐり込む ➔ 暖気が急に押し上げられる ➔ 積乱雲などが発達しやすい ➔ 強い雨が短時間に降りやすい ➔ 通過後は気温が下がりやすい

19．停滞前線

暖気と寒気の勢力がほぼ同じになると、どちらの空気も大きく前進できなくなることがあります。このような前線を停滞前線といいます。

停滞前線が長く同じ場所にとどまると、雨や曇りの日が続くことがあります。日本の梅雨の時期には、梅雨前線と呼ばれる停滞前線が日本付近にでき、雨や曇りの日が多くなります。

20．閉塞前線

低気圧が発達していくと、寒冷前線が温暖前線に追いつくことがあります。このとき、暖気が地上から押し上げられ、寒冷前線と温暖前線が重なったような状態になります。このようにしてできる前線を閉塞前線といいます。

21．温帯低気圧

日本付近の天気に大きな影響を与える低気圧の一つが温帯低気圧です。温帯低気圧は、基本的に西側に寒冷前線、東側に温暖前線を伴うことがあります。

温帯低気圧が西から東へ移動すると、その地域では前線の通過に伴って天気が変化していきます。そのため、天気図を見るときには、低気圧の位置 ➔ 前線の位置 ➔ 自分のいる場所との位置関係 を見ることが重要です。

22．偏西風

日本付近の中緯度地域の上空では、西から東へ向かって吹く偏西風が吹いています。このため、日本付近の高気圧や低気圧は、基本的に西から東へ移動していきます。

「天気は西から東へ変わっていくことが多い」といわれるのは、このような大気の動きと関係しています。（※ただし実際の天気の変化は気圧配置や前線なども関係します）

23．季節風

季節によって、ほぼ決まった方向から吹く風を季節風といいます。日本では夏：南東寄りから / 冬：北西寄りから吹く季節風が特徴的です。

これは、陸地と海では温まり方・冷え方が異なることや、大陸と海洋の温度差などと関係しています。

24．海風と陸風

海と陸では、温まり方と冷え方が違います。陸地は海よりも温まりやすく、冷えやすいという特徴があります。

昼：海風

昼間は太陽によって陸地が海よりも早く温められます。すると陸上の空気が暖められて上昇し、陸上の気圧が低くなります。そのため、海 ➔ 陸 へ風が吹きます。これを海風といいます。

夜：陸風

夜になると陸地は海よりも早く冷えます。すると陸上の空気が冷えて下降し、陸上の気圧が高くなります。そのため、陸 ➔ 海 へ風が吹きます。これを陸風といいます。海風と陸風を合わせて海陸風といいます。

25．気団

気団とは、広い範囲で、気温や湿度などの性質がほぼ一様になった空気のかたまりです。気団は、長い時間その土地の上にとどまることで、その土地の特徴を受けます。

  • 寒い地域でできた気団 ➔ 冷たい
  • 暖かい地域でできた気団 ➔ 暖かい
  • 海の上でできた気団 ➔ 水蒸気を多く含み湿っている
  • 大陸上でできた気団 ➔ 比較的乾燥している

26．日本周辺の主な気団

日本の天気に関係する代表的な気団には以下のものがあります。

  • シベリア気団：冬に大陸上で発達する、冷たく乾燥した気団。
  • 小笠原気団：夏に発達する、暖かく湿った気団。
  • オホーツク海気団：夏の前後などに日本付近へ影響する、冷たく湿った気団。

気団の性質を覚えるときは、「どこでできたか」➔「どんな気温・湿度になったか」➔「日本に来たらどんな天気になるか」まで考えると理解しやすくなります。

27．春の日本の天気

春は、移動性高気圧と低気圧が交互に日本付近を通過することが多くなります。そのため、晴れ ➔ 曇り・雨 ➔ 晴れ のように、天気が数日おきに変化しやすくなります。

28．梅雨の天気

初夏になると、日本付近に梅雨前線ができやすくなります。梅雨前線は、暖かく湿った空気と、比較的冷たく湿った空気の境界付近にできる停滞前線です。停滞すると雨や曇りの日が増えます。その後、夏の気圧配置が強まると梅雨前線が北上し、梅雨が明けます。

29．夏の日本の天気

夏には、暖かく湿った小笠原気団の勢力が強くなります。太平洋側に高気圧が張り出し、代表的な気圧配置として南高北低が見られます。晴れの日が続き、蒸し暑くなります。

また、強烈な日射で上昇気流が発生しやすいため、午後から積乱雲が発達して激しい雷雨（夕立）になることがあります。

30．秋の日本の天気

秋になると夏の勢力が弱まり、秋雨前線が日本付近に停滞して曇りや雨の日が続くことがあります。また、夏から秋にかけては最大風速が 17.2 m/s 以上となった熱帯低気圧である台風が接近・上陸し、大雨や強風をもたらします。

31．冬の日本の天気

冬には、ユーラシア大陸上で発達したシベリア気団が影響を与えます。代表的な気圧配置が西高東低（西に高気圧、東に低気圧）です。

この気圧配置によって北西から季節風が吹き、日本海を通るときに大量の水蒸気を受け取ります。湿った空気が日本海側の山地にぶつかって上昇すると雲が発達し、日本海側では雪が降りやすくなります。一方、山を越えた空気は乾燥するため、太平洋側では晴れて乾燥しやすくなります。

32．日本の天気を理解する「一本の流れ」

ここまでの内容は、すべてバラバラの知識ではありません。例えば冬の日本海側の雪を考えてみましょう。

シベリア気団（冷たく乾燥）➔ 北西季節風 ➔ 日本海を通過して水蒸気を受け取る ➔ 湿った空気になり山地で上昇 ➔ 気圧低下で空気膨張 ➔ 温度低下して水蒸気が凝結 ➔ 雲が発達して雪が降る

このように、「空気が動く ➔ 気圧が変わる ➔ 温度が変わる ➔ 水蒸気が変化する ➔ 雲ができる ➔ 雨や雪が降る」というつながりを意識することが大切です。

33．地学で特に重要な「原因 ➔ 結果」

  • 気圧：高度が高くなる ➔ 上にある空気が少なくなる ➔ 気圧が低くなる
  • 圧力：同じ力で押す ➔ 面積が小さいほど圧力が大きい
  • 湿度：気温が高くなる ➔ 飽和水蒸気量が大きくなる
  • 露点：空気を冷やす ➔ 飽和水蒸気量が小さくなる ➔ 湿度が上がる ➔ 露点に達すると凝結が始まる
  • 雲：空気が上昇 ➔ 気圧が低下 ➔ 空気が膨張 ➔ 温度が低下 ➔ 水蒸気が凝結 ➔ 雲ができる
  • 高気圧：下降気流 ➔ 雲ができにくい ➔ 晴れやすい
  • 低気圧：上昇気流 ➔ 雲ができやすい ➔ 雨や曇りになりやすい
  • 温暖前線：暖気が進む ➔ 寒気の上にはい上がる ➔ 広い範囲で弱い雨が長く続きやすい
  • 寒冷前線：寒気が進む ➔ 暖気の下にもぐり込む ➔ 暖気が急上昇 ➔ 積乱雲が発達し強い雨が短時間に降りやすい
  • 冬の日本海側：シベリア気団 ➔ 北西季節風 ➔ 日本海から水蒸気獲得 ➔ 山地で上昇 ➔ 雲が発達して雪

まとめ

中学2年の地学で最も大切なのは、用語を丸暗記することではありません。「空気の動きと気圧」「気温と飽和水蒸気量」「水蒸気と凝結」「雲と降水」「高気圧・低気圧」「暖気・寒気と前線」「気団と季節」が一本の線でつながっていることを理解することです。

特に重要な「なぜ雲ができるのか？」の流れ
空気が上昇する ➔ 気圧が下がる ➔ 空気が膨張する ➔ 温度が下がる ➔ 露点に達する ➔ 水蒸気が凝結する ➔ 雲ができる

この流れを自分の言葉で説明できれば、天気図や前線、季節ごとの日本の天気についても、単なる暗記ではなく「なぜそうなるのか」を考えて解けるようになります。
